# 🌐 Portfólio Pessoal

Este é o meu site de portfólio, criado para apresentar meus projetos, habilidades e formas de contato.  
O objetivo é ter um espaço central onde qualquer pessoa possa conhecer meu trabalho como desenvolvedor web.

---

## 🚀 Tecnologias utilizadas
- **HTML5**  
- **CSS3**  
- **JavaScript**
  
---

## 📂 Estrutura do projeto
- `index.html` → Página inicial do portfólio  
- `styles/` → Arquivos CSS para estilização  
- `script.js` → Lógica de interação (event listeners, redirecionamentos)  
- `images/` → Imagens dos projetos e ícones  
- `icon/` → Ícones das redes sociais e elementos gráficos  

---

## 🖼️ Conteúdo
- **Quem sou?** → Breve apresentação pessoal  
- **Habilidades** → Ícones das tecnologias que domino  
- **Projetos** → Lista de projetos com descrição e link para o GitHub  
- **Contato** → Links para minhas redes sociais e e-mail
